Option SLAM

Veille informationnelle

Qu'est-ce que la veille informationnelle ?

La veille informationnelle consiste à surveiller de manière systématique et régulière les évolutions, nouveautés et bonnes pratiques dans le domaine de l'informatique.

Pour un futur technicien SISR, elle est essentielle : elle permet d'anticiper les changements (nouvelles versions d'outils, failles de sécurité, tendances comme l'IaC ou le cloud), de rester compétent sur le marché du travail et d'alimenter sa réflexion professionnelle.

Ma démarche pour m'informer

Je structure ma veille informationnelle autour de deux sources principales complémentaires :

  • Un agrégateur de flux RSS personnalisé : j'utilise Inoreader pour centraliser les articles de blogs techniques et médias spécialisés (HashiCorp, Red Hat, The New Stack). Chaque semaine, je parcours les titres et sauvegarde les articles les plus pertinents.
  • Les communautés Reddit : je consulte régulièrement les subreddits r/sysadmin et r/sysadmin_fr. Ces forums d'échange me permettent de découvrir des retours d'expérience concrets.

L'IaC — Infrastructure as Code

L'Infrastructure as Code (IaC) est une pratique qui consiste à décrire et gérer l'infrastructure informatique (serveurs, réseaux, bases de données, pare-feux…) à l'aide de fichiers de configuration manipulables comme du code source. Au lieu d'effectuer des actions manuelles, on écrit des scripts qui automatisent la création, la modification et la suppression des ressources.

Pourquoi ce sujet me correspond-il ?

  • Elle demande une rigueur de développeur : écrire du code propre, structuré, versionné (avec Git), et parfois concevoir de petites logiques algorithmiques dans les templates Terraform ou les playbooks Ansible.
  • Elle s'applique directement aux métiers de l'administration systèmes et réseaux : déployer des VM, configurer des pare-feux, gérer des clusters, assurer la reproductibilité des infrastructures.
